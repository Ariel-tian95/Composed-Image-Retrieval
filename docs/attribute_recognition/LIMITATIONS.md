# 服装属性识别模块局限性

| 限制 | 对结果的影响及后续核验 |
| --- | --- |
| 编码器来源 | 本地官方检查点及源码已经校验，可作为 CPU 功能候选。Kaggle 历史编码器的哈希和源码环境缺失，历史特征空间的等价性仍待验证。 |
| 多标签监督 | 观测数据有确认正例，确认负例为零。代理指标会把漏标正例的预测计为不匹配。后续需要独立补标样本核实真实精确率。 |
| 校准与拒识 | softmax 和 sigmoid 分数未经校准。unknown 表示阈值未通过，不能据此判定服装没有该属性。 |
| 稀有类别 | Binders 无测试支持，召回不可估计。其他低支持类别的逐类指标波动较大。 |
| 重复样本 | 已移除跨集合完全重复特征组，近重复候选仍保留。现有特征不能确认商品或原图相同。 |
| 目标域 | FashionIQ 属性识别表现尚未验证。既有 FashionIQ 检索基线属于另一项实验。 |
| 接口验收 | CPU 已完成端到端功能验证。三条输入是一张制服照片和两张生成测试图，三张真实服装照片验收、GPU 测试和成员 A 正式联调待完成。 |

证据见 [REPORT_SOURCES](REPORT_SOURCES.md) 的 E2、E3、E5、E7 和 E8。
