## 混淆与置信度

- 服装类别最常见混淆为 Casual Dresses → Dresses（77 次）。Binders 在测试集为零支持。
- 袖长最常见混淆为 Long Sleeved → Sleeveless（59 次）。领口最常见为 V-Necks → Round Neck（113 次）。
- 按确认正例漏出次数，颜色 Green 漏出 239/562，图案 Pin Stripes 漏出 24/36，材质纹理 Polyester 漏出 162/407。
- 正确／错误预测的最高 softmax 均值分别为服装类别 0.543／0.384、袖长 0.838／0.632、领口 0.586／0.442。分数分布有重叠，未进行概率校准。证据 E7。
