# 服装图像六维属性识别模块设计、实验与交付报告

## 第一章 项目背景与负责范围

本模块服务于「面向细粒度属性操作的零样本组合图像检索方法研究」。项目以 Context-I2W 为研究基础。本人负责把服装图像转换为结构化属性及预测分数，为团队后续的属性比较提供输入。阶段成果包括数据标签整理、六个预测头、冻结特征上的独立评估和 CPU 图片推理候选接口。文字解析、属性状态转移和 IVS 反馈属于后续团队研究范围。证据 E1、E4–E8。

## 第二章 数据准备

使用 iMaterialist Fashion Attribute（2018）的 Marqo 数据版本。既有特征由冻结的 CLIP ViT-L/14 提取。按分片编号和行顺序配对特征与标签，成对跳过空特征分片 00012 及对应 2,048 条标签，保留 37,952 条 768 维 float32 特征。核验了维度、有限值与 L2 范数，并回查 138 条边界及抽样记录。证据 E1。

六个属性共保留 167 个类别。映射按观察到的官方原子短语解析复合值，保留可确认的多个取值。缺失、冲突或不适用标签单独屏蔽，其他属性可继续提供监督。多标签的未出现类别保持未知，确认负例为零。证据 E1、E2。

## 第三章 数据划分

按 item_ID、种子 20261127 固定 8:1:1 划分。对完全重复向量按组处理，排除 16 个跨集组中的 51 行。源划分和原始特征保留。证据 E2、E3。

| 索引 | 训练 | 验证 | 测试 |
| --- | ---: | ---: | ---: |
| 原始划分 | 30,362 | 3,795 | 3,795 |
| 安全划分 | 30,334 | 3,784 | 3,783 |

安全索引无跨集 item_ID 或完全相同的向量。测试仍与训练存在 64 对、与验证存在 3 对余弦相似度达到 0.98 的候选，特征相似只能提示近重复风险。证据 E3、E7。

## 第四章 模型训练

各属性使用独立的 Linear(768, k) 分类头。服装类别 82 类、颜色 20 类、袖长 3 类、领口 8 类、图案 20 类、材质纹理 34 类。CLIP 保持冻结。单标签仅在有效目标上使用交叉熵，类权重取训练频次平方根倒数并截断至 [0.5, 3.0]。优化器为 AdamW，学习率 0.001，权重衰减 0.0001，批量 256，最多 50 轮，按验证 macro-F1 选最佳轮。证据 E4。

多标签使用弱负例 BCE 基线，仅使用对应属性至少有一个确认正例的样本。正例权重为 1，同组未观察的类仅在实验损失内作为弱负例。比较 0.1、0.3、1.0 后，颜色选 0.3，图案和材质纹理选 0.1。权重 1.0 的图案和材质试验因预测几乎全空提前停止。证据 E5、E6。

## 第五章 验证与独立测试结果

单标签最佳轮仅由验证集确定。三个多标签候选在验证集比较弱负权重并冻结阈值，再在独立安全测试集上评估。以下结果已与第 4 步 JSON、逐类 CSV 和混淆矩阵口径核对。证据 E4–E7。

| 单标签属性 | 最佳轮次 | 验证 Accuracy | 验证 Macro-F1 |
| --- | ---: | ---: | ---: |
| 服装类别 | 42 | 54.27% | 48.96% |
| 袖长 | 43 | 85.30% | 82.02% |
| 领口 | 35 | 59.71% | 48.73% |

| 属性 | 有效样本 | 测试 Accuracy | 测试 Macro-F1 |
| --- | ---: | ---: | ---: |
| 服装类别 | 3,363 | 53.55% | 47.17% |
| 袖长 | 2,347 | 86.11% | 82.19% |
| 领口 | 2,175 | 60.23% | 47.08% |

| 属性 | 有效样本 | 代理 Macro-F1 | 代理 Micro-F1 | 全测试 unknown |
| --- | ---: | ---: | ---: | ---: |
| 颜色 | 2,460 | 32.86% | 64.57% | 1.00% |
| 图案 | 632 | 42.15% | 64.27% | 23.08% |
| 材质纹理 | 2,473 | 31.12% | 57.65% | 13.27% |

多标签代理计分仅使用有对应确认正例的样本。未观察到的类暂按 0 计分，可能含漏标正例，因此代理 F1 只描述预测与观察标签的吻合。unknown 以全部安全测试样本为分母。单标签 Macro-F1 只平均有测试支持的类，Binders 召回不可估计。证据 E7。

最常见混淆为 Casual Dresses → Dresses（77 次）、Long Sleeved → Sleeveless（59 次）和 V-Necks → Round Neck（113 次）。正确／错误最高 softmax 均值依次为 0.543／0.384、0.838／0.632、0.586／0.442。图案 unknown 比例最高。逐类漏出与低频类覆盖见实验结果。证据 E7。

## 第六章 推理接口

predict(image_path) 按 RGB、官方 224 像素预处理、Context-I2W encode_image、768 维 L2 归一化和六头推理得到 JSON。predict_from_features(features) 直接处理同规格的 float32 单位范数特征，两入口共享后处理。单标签用 softmax top-1，多标签用 sigmoid，分别采用颜色 0.600、图案 0.625（Floral 0.650）、材质纹理 0.775（Leather 0.725）。证据 E6、E8。

每个属性返回 value、confidence、status、probabilities。对多标签，confidence 列表与 value 逐项对应，unknown 表示该属性没有任何类别通过冻结阈值。全部逐类分数均可保留，分数未经概率校准。证据 E8。

## 第七章 功能测试与交付

随机抽取 128 条安全测试特征，与冻结预测逐条核对。六头标签、顺序和状态一致，最大概率绝对误差约 7.75×10⁻⁷。模型在单进程复用初始化。CPU 上实际通过三次完整图片前向，输入为一张本地制服照片及两张生成测试图。六属性输出可转换为合法 JSON。证据 E8。

第 5B 步独立配置源码和检查点，在搬移后的目录与独立工作目录中运行一张已有本地照片。外置权重缺失时给出明确错误。功能验证覆盖加载、预处理、编码和结构化输出。证据 E8。

## 第八章 局限性

Kaggle 历史编码器与本地编码器的等价性尚未确认。多标签缺少确认负例，代理指标受漏标影响。模型分数未经校准，近重复候选和低频类别限制独立测试解释。FashionIQ 目标域属性识别、GPU 前向、三张真实服装照片验收和成员 A 正式联调尚未完成。证据 E2、E3、E7、E8。

## 第九章 交付与后续工作

团队分支提供接口、调用示例、配置、词表、冻结阈值、校验脚本和报告。七份权重通过组内渠道配置，并按 SHA256 核验。成员 A 可按接口 README 安装环境、检出官方源码并运行校验脚本。接口输出供 Context-I2W 检索项目后续使用，下一阶段安排是组内联调与目标域属性验证。证据 E8。
