# 成员 B：属性映射与识别可行性预实验

状态：数据清单、人工标注入口、预测与评价脚本已准备；真实标签待人工填写，GPU 属性预测待运行，可靠性指标尚不存在。所有交付统一 memberb，不合并 main。

## 本次范围

为了使用现有数据快速开展诊断，从 FashionIQ 验证图库固定选择150个单件商品图像ID，50张开发、100张评估。按三个检索子集取样，不把子集名当作商品类别真值。检查了ID和SHA256不重叠，并排除已选图片间dHash距离≤4的相似图片；此启发式不能保证全部近重复已排除。尚无真实属性标签，因此不宣称按属性类别平衡。

这是目标域属性诊断样本，不是外部独立基准。冻结检索模型与其基线结果，不以这些样本训练核心检索网络，不将属性调试后的结果直接作为原始零样本基线。若后续拟用于模型训练，另用外部属性数据并重新规定评价划分。

## 第一步：人工标签

解压“人工标注包.zip”，双击“打开这里标注.html”。先仅查看开发集，填写标注者、三项属性和必要备注，然后导出 labels.csv。页面不显示模型预测；浏览器缓存仅作便利，务必导出保存。评估集由另一成员盲标为佳，锁定提示词与规则后再使用，不能反复查看评估指标调参。标注者分歧应保留并协商，不确定就标 uncertain，遮挡用 not_visible。

页面使用600像素以内的缩放JPEG预览，模型仍读取原始PNG；对颜色或细节有疑问时查看原图，不确定就记录争议。标签包不包含模型预测。

本轮只评价单一主属性，刻意缩小第十周的多标签词表：主颜色、袖长、主图案。多色无明显主色选 multicolor；不同主图案难分主次选 mixed。不是把未来多标签任务简化后宣称全部完成。

- 袖长：sleeveless 无袖；short 不到肘；elbow 肘附近；three_quarter 肘与腕之间；long 腕附近。无袖与被遮住的袖子不能混淆。
- 图案：plain 素色；stripe 条纹；check 格纹；dot 圆点；floral 花卉；letters_graphics 文字/图形；mixed 混合。小商标、衣服多层叠穿、背景干扰需备注并统一规则。
- 颜色为可见主体服装主色，不是背景颜色，不推断真实材质或不可见部分。

## 第二步：Kaggle 预测

运行 notebooks/attribute_pilot.ipynb。复用现有官方权重中的冻结CLIP编码器，仅比较候选属性文字；不用IVS/VTE，不新增训练。脚本输出每项候选余弦分数及前两名差值，不把分数称为校准置信概率。模型预测不能自动填进人工真值。

## 第三步：评价

标注CSV中字段取值必须与 attribute_values.json 相符。真实标签必须附reviewer，未知不作负标签。评价脚本先计算开发集，报告已标样本量、标签覆盖、准确率、宏F1、逐类支持量和混淆矩阵。空标签明确返回 pending_labels，不生成虚构准确率。开发集只有少量样本时不能宣称统计可靠性；类别缺失与小支持量需在报告解释。

阈值和提示词只能在开发集选择，评估集只用于冻结方案后的评估。本版尚未实现置信校准及反馈门控，也没有预设“80%即合格”的标准。

## 映射验证（④）

mapping_review_queue.csv为25项待核查表，提供Fashionpedia验证标注中出现的源标签计数和样本ID。当前证据来自整图属性，不能确认属于同一件衣服。下一步需要实例级标注和对应图片，按服装实例核对，成员C确认语义后才能提升为已验证映射。尤其short (length)不能无条件视为短袖。颜色没有现成源标签监督，不编造。
